This Project was made for a mini-Hackathon competition held in [SLIIT](https://www.sliit.lk) for the Feb 2026 Orientation Batch.
  
[Botanix](https://yasithbuckeroo2026.wixsite.com/botanix) is a website with an AI model made to identify most common plant diceases in Sri Lanka, 
  So it can help existing farmers to confirm the diseases and help new farmers get into the industry with one less problem to worry about.

The main website is made with [Wix](https://wix.com), And the website hosting the AI model is made with HTML, CSS and Javascript.

The AI model is made through [Teachable Machine](https://teachablemachine.withgoogle.com), but limited to 20-30 images per each disease due to the scarcity of the correct images for the diseases, on the internet.

The webpage hosting the AI Model is hosted on [Vercel](https://www.vercel.com) as it was free to host.
